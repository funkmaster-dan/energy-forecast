# Contributor instructions
Personal household project: keep implementations simple. Python 3.13, uv, Ruff and focused pytest; web uses npm and TypeScript. Run `uv run ruff check .`, `uv run pytest`, and `cd web && npm run build`. Inputs use UTC intervals, explicit units and AC/DC boundaries. Missing values are never zero. Preserve observations, revisions and forecast vintages. Keep forecasts advisory; no device actuation. Never commit credentials or household telemetry. Configuration/model changes invalidate export leases. See docs/architecture.md and docs/status.md for scope and validation limits.
